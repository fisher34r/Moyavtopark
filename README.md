## 🌟 Ключевые возможности

### 1. 📋 Учёт и журнал рейсов
- **Полная карточка рейса:** дата погрузки/выгрузки, культура (пшеница, ячмень, кукуруза, подсолнечник и др.), пункты маршрута, вес нетто (т), объём (м³), ставки, ТТН, номер авто и прицепа, ФИО водителя, заказчик.
- **Интерактивные спойлеры по месяцам:** журнал сгруппирован по месяцам (текущий месяц раскрыт, прошлые компактно свернуты).
- **Гибкая фильтрация и поиск:** выбор периода (день, неделя, месяц, квартал, год, **произвольный диапазон дат**), фильтр по статусу рейса (*В пути*, *Выгружен*, *Оплачен*), водителю, культуре или автомобилю.
- **Пакетные операции:** выбор нескольких рейсов для массовой смены статуса, водителя, ставки или удаления в один клик.

### 2. 🧮 Профессиональный калькулятор рейсов
- **Расчёт стоимости по 3 типам тарифов:**
  - `₽ / тонна`
  - `₽ / км`
  - `₽ / т·км` (тонно-километр)
- **Расчёт рентабельности и желаемой маржи:** моментальный расчёт чистой прибыли рейса с учётом расходов на дизтопливо, зарплату водителя (в % от фрахта), систему «Платон», весовые и сопутствующие расходы.
- **Кнопка «Кругорейс (×2 / ÷2)»:** удобное переключение между расстоянием в одну сторону и кругорейсом.
- **Умный ввод:** автодополнение и подсказки населённых пунктов прямо при вводе, автоматическая очистка поля при клике (select-on-focus).

### 3. 🗺️ Автоматический расчёт расстояний (OSRM + Яндекс)
- **Умная маршрутизация:** автоматический расчёт километража между пунктами погрузки и выгрузки по дорожной сети через OpenStreetMap / OSRM.
- **Локальный офлайн-кэш:** ранее рассчитанные маршруты сохраняются на устройстве и открываются мгновенно даже без интернета.
- **Запас на объезды и маневрирование:** настраиваемый коэффициент (+0%, +5%, +7%, +10%) для точного соответствия реальному одометру зерновоза.
- **Поддержка Яндекс Карт:** возможность подключения персонального API-ключа Яндекс для максимальной точности промзон, весовых и полевых дорог РФ.

### 4. ⛽ Учёт расхода топлива и зарплаты
- **Автоматический расчёт ДТ:** затраты на топливо рассчитываются по формуле `(км / 100) × норма × цена`.
- **Историческая точность:** изменение текущих цен и норм топлива в настройках не ломает финансовую отчётность уже завершённых прошлых рейсов.
- **Начисление ЗП водителя:** расчёт сдельной оплаты от фрахта (например, 18–25%) в реальном времени.

### 5. 🚚 Управление автопарком, заправками и документами
- **6 разделов автопарка:** Транспорт (ТС), Водители, ТО и Ремонт, **Заправки (чеки с АЗС)**, **Документы (ОСАГО, КАСКО, ДК)**, Аналитика.
- **Учёт заправок:** ведение журнала чеков с АЗС (литры, сумма, одометр, сеть АЗС) с привязкой к конкретному тягачу или сцепке.
- **Контроль документов:** отслеживание сроков действия страховок, диагностических карт и пропусков с предупреждениями об истечении срока.
- **Справочник водителей:** учет контактов, графика смен, процента от ставки фрахта и привязка к технике.

### 6. 📊 Аналитика, TCO и умные фильтры
- **Фильтрация в один клик:** выборка финансовых показателей по периоду (месяц, всё время), конкретному автомобилю или водителю.
- **Расчёт совокупной стоимости владения (TCO):** честный учёт расходов (топливо по чекам + ремонт + документы + зарплата + прочие расходы).
- **Ключевые метрики эффективности:** себестоимость 1 км пробега, чистая прибыль, выручка, доля зарплаты водителей от фрахта.
- **Экспорт отчётов:** выгрузка сводных реестров и ведомостей в форматы **Excel / CSV**.

### 7. 💾 Безопасность и бэкапы
- Полное локальное хранение данных в базе данных Room (SQLite).
- Экспорт и импорт полной резервной копии базы данных в файл JSON.
- Возможность выбора: *«Добавить к текущим»* или *«Заменить всё»*.

## 🚀 Установка и сборка

### Скачать готовый APK
Каждый коммит в ветку `main` автоматически собирает свежий APK в разделе **[Releases](../../releases)**.
1. Перейдите в раздел **Releases**.
2. Скачайте `app-debug.apk` последней версии на Android-смартфон и установите.

### Сборка из исходного кода
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/fisher34r/Moyavtopark.git
   cd Moyavtopark
   ```
2. Откройте проект в **Android Studio Ladybug (2024.2+)** или новее.
3. Соберите через Gradle в терминале:
   ```bash
   # Windows
   .\gradlew.bat assembleDebug

   # Linux / macOS
   ./gradlew assembleDebug
   ```
   Собранный файл появится в каталоге:  
   `app/build/outputs/apk/debug/app-debug.apk`

## ⚙️ Настройки и API-ключи

Приложение готово к работе сразу «из коробки» полностью бесплатно и не требует обязательных регистраций:
- **Маршруты:** по умолчанию используется бесплатный сервер OSRM и база OpenStreetMap.
- **Яндекс Геокодер (опционально):** если вам нужна максимальная детализация промзон и элеваторов РФ, укажите ключ Яндекс в меню *«Настройки» ➔ «API-ключ Яндекс»*.
